EasyPDF cho Windows — Hướng dẫn sử dụng

Xem, chú thích và xử lý PDF ngay trên máy tính — nhanh, nhẹ, chạy ngoại tuyến.

1. Bắt đầu nhanh

  • Mở file: nút Mở file (Ctrl+O), kéo thả file PDF vào cửa sổ, hoặc bấm một file trong danh sách Tệp mở gần đây ở tab Trang chủ.
  • Tab Trang chủ luôn là tab đầu tiên (không đóng được): có nút Mở file, banner và danh sách file gần đây.
  • Nhiều tab như trình duyệt: Ctrl+T tab mới, Ctrl+W đóng, Ctrl+Shift+T mở lại tab vừa đóng, kéo tab để đổi thứ tự, chuột giữa để đóng, chuột phải để đóng các tab khác.
  • Easy PDF nhớ trang và mức phóng của từng file, và mở lại các file lần trước khi khởi động (tắt trong menu Trợ giúp).

2. Xem và tìm kiếm

  • Phóng to/thu nhỏ: Ctrl+lăn chuột, hoặc ô mức phóng trên thanh công cụ. Ctrl+0 vừa trang, Ctrl+2 vừa ngang, Ctrl+1 100%. Phóng tới 6400% vẫn sắc nét (bản vẽ A0/A1).
  • Cuộn: lăn chuột, phím mũi tên, PgUp/PgDn, Home/End, hoặc kéo trang bằng công cụ Bàn tay (H). Ctrl+G tới trang bất kỳ; Alt+← quay lại vị trí trước.
  • Xoay khung nhìn: Ctrl+R (phải), Ctrl+Shift+R (trái). Việc xoay này chỉ là cách xem; muốn xoay vĩnh viễn hãy dùng menu chuột phải ở khung trang nhỏ.
  • Tìm chữ: Ctrl+F, gõ vào ô tìm kiếm (hỗ trợ tiếng Việt có dấu); F3 / Shift+F3 kết quả sau / trước. Kết quả được tô sáng.
  • Chọn chữ theo vùng: bấm công cụ Chọn chữ (T) rồi kéo chuột; chữ trong vùng được chép vào bộ nhớ tạm khi thả chuột.
  • Từ điển: nháy đúp một từ tiếng Anh để xem nghĩa tiếng Việt (ngoại tuyến). Dịch đoạn đã chọn cần Internet.
  • Toàn màn hình / trình chiếu: F11 (ẩn thanh bên và banner). F9 bật/tắt thanh bên.

3. Thanh bên: trang nhỏ và mục lục

  • Tab Trang nhỏ: ô đầu danh sách là banner (cuộn cùng danh sách). Bấm một trang để tới trang đó.
  • Chọn nhiều trang: Ctrl+bấm (thêm/bớt), Shift+bấm (một dãy), Ctrl+A (tất cả), Esc (bỏ chọn).
  • Kéo thả để đổi thứ tự trang: kéo trang (hoặc cả nhóm đã chọn) tới vị trí mới — vạch đỏ cho biết chỗ thả. Chương trình tạo một file mới theo thứ tự mới, file gốc không bị sửa.
  • Dấu ★: đánh dấu các trang quan trọng; sau đó chọn lại bằng "Chọn các trang đã đánh dấu ★" để trích, in, xuất ảnh…
  • Tab Mục lục: bookmark của tài liệu; bấm để nhảy tới mục.

5. Menu chuột phải trên khung xem

Khi đang dùng công cụ Bàn tay hoặc Chọn chữ, bấm chuột phải lên trang: tra từ điển từ dưới con trỏ, sao chép văn bản / ảnh của trang, lưu trang thành ảnh, xuất văn bản, trích ảnh nhúng, trích trang này ra PDF mới, in trang này, đánh dấu ★, xem thuộc tính, OCR, xoá nền scan.

6. Chú thích

Bấm Chú thích để mở thanh công cụ: bút vẽ, đường thẳng, mũi tên, hình chữ nhật, elip, đám mây sửa đổi, highlight, ghi chú, viết chữ, con dấu / chữ ký, chèn ảnh, tẩy/che thông tin, đo, kính lúp…

  • Dùng Con trỏ để chọn, di chuyển, đổi cỡ, xoay chú thích. Ctrl+Z / Ctrl+Y hoàn tác / làm lại.
  • Chuột phải vào chú thích: xoá, sửa nội dung, đưa lên/xuống lớp, đổi màu.
  • Ảnh chèn / chữ ký: chuột phải → Xoá nền ảnh để chữ ký trong suốt; Xoay 90°; Lưu ảnh (PNG nền trong suốt) để dùng cho việc khác; Sao chép ảnh để dán sang ứng dụng khác.
  • Lưu: Ctrl+S ghi chú thích vào PDF (hỏi trước khi ghi đè); Ctrl+Shift+S lưu thành file mới.
  • Vùng Che thông tin (redact) biến trang thành ảnh để dữ liệu bị che không thể khôi phục.

7. Thao tác trang và công cụ khác

  • Menu Trang / nút Công cụ ▾: xoay, xoá, trích, sắp xếp lại, chèn, trang trắng, tách (mỗi N trang / theo mục lục / theo khoảng), ghép nhiều file, đánh số trang, watermark, bookmark.
  • Chế độ Tách trang và Gộp file (góc phải thanh tab): xem lưới các trang, chọn, xoay, xoá, rồi xuất một file hoặc tách từng trang.
  • So sánh 2 bản vẽ (revision), Nén giảm dung lượng, In (kèm chú thích, 1–2 trang/tờ), lưu / mở phiên làm việc (.json).
  • Các thao tác ghi tệp luôn tạo file mới và chạy nền; thanh trạng thái báo tiến độ.

8. Ngôn ngữ và quảng cáo

  • Giao diện 6 ngôn ngữ: Tiếng Việt, English, Bahasa Indonesia, 한국어, 日本語, Filipino — menu Ngôn ngữ.
  • Banner quảng cáo hiện ở tab Trang chủ và đầu danh sách trang nhỏ; tự ẩn khi xem toàn màn hình, tắt thanh bên hoặc ở chế độ Tách trang / Gộp file.

9. OCR — làm file ảnh tìm kiếm được

Dùng cho file PDF dạng ảnh / bản scan (không chọn hay tìm được chữ).

  1. Bấm nút OCR ▾ trên thanh công cụ rồi chọn trang: trang đang xem, các trang đang chọn ở cột trang nhỏ, toàn bộ hoặc khoảng trang (hoặc menu Công cụ → OCR, hoặc chuột phải vào trang nhỏ → OCR).
  2. Chọn ngôn ngữ (Việt + Anh / Anh / Việt), kết quả (PDF có lớp chữ hoặc chỉ .txt) và độ phân giải (300 dpi khuyên dùng).
  3. Chọn nơi lưu. Chương trình chạy nền, bạn vẫn xem tài liệu bình thường; xong sẽ tự mở file mới.

File kết quả giữ nguyên hình ảnh trang nhưng có lớp chữ ẩn: Ctrl+F tìm được chữ, bôi chọn / sao chép được. OCR nhận dạng tốt nhất với chữ in rõ nét; hãy chạy Xoá nền bản scan trước nếu bản scan ố vàng hoặc có bóng.

Cần thành phần OCR (thư mục ocr cạnh EasyPDF.exe). Nếu thiếu, hãy chạy lại bộ cài và tích mục "OCR".

10. Xoá nền bản scan

Làm trắng nền giấy ố vàng, bóng đổ, nền xám của bản scan và làm chữ rõ hơn.

  1. Bấm nút Xoá nền trên thanh công cụ (hoặc chuột phải vào trang nhỏ → Xoá nền bản scan để chỉ làm trang đã chọn).
  2. Chọn mức (Nhẹ / Vừa / Mạnh), màu (Giữ màu / Thang xám / Đen trắng — nhỏ nhất) và độ phân giải.
  3. Kết quả là file mới; trang không chọn được giữ nguyên.
Các trang được xử lý trở thành ảnh nên chữ chọn được (nếu có) sẽ mất. Muốn tìm kiếm được: xoá nền xong, chạy OCR trên file mới.

11. Mở file Word, Excel, PowerPoint

Easy PDF đọc được tệp .doc, .docx, .rtf, .odt, .xls, .xlsx, .csv, .ods, .ppt, .pptx, .odp: mở như file PDF (nút Mở file, kéo thả, hoặc chuột phải tệp → Open with).

  • Tệp được chuyển sang PDF để xem bằng phần mềm đã cài trên máy: ưu tiên Microsoft Office (chạy ẩn, chỉ đọc, không chạy macro), nếu không có thì dùng LibreOffice (miễn phí).
  • Lần đầu mất vài giây; bản PDF được lưu đệm nên mở lại gần như tức thì. Tệp gốc không bị sửa.
  • Sau khi mở, mọi công cụ đều dùng được: tìm kiếm, chú thích, trích trang, OCR… File mới được đặt cạnh tệp gốc.
  • Ctrl+S trên tab Office = Lưu thành PDF (kèm chú thích nếu có).
Nếu máy chưa có Microsoft Office hay LibreOffice, Easy PDF sẽ báo và mở trang tải LibreOffice. Bố cục có thể khác đôi chút khi chuyển bằng LibreOffice.

13. Câu hỏi thường gặp

Vì sao thao tác không sửa thẳng file đang mở?

Để an toàn: mọi thao tác trang đều tạo file mới. Bạn so sánh rồi mới thay file cũ.

File PDF có mật khẩu?

Chương trình hỏi mật khẩu khi mở; các thao tác sau đó dùng lại mật khẩu này.

OCR báo thiếu thành phần?

Chạy lại bộ cài Easy PDF và tích mục "OCR", hoặc chép thư mục ocr cạnh EasyPDF.exe (bản Portable đã kèm sẵn).

Cuộn trang bị giật?

Trang rất nặng (bản vẽ khổ lớn) cần thời gian vẽ nét: chương trình hiện ngay bản mờ rồi thay bằng nét sắc. Tăng bộ nhớ đệm không cần thiết vì chương trình tự giới hạn theo RAM.

Hạn giới

Tệp Office chỉ được chuyển để xem (chưa xuất PDF → Word) — dùng Xuất văn bản (.rtf) để mở bằng Word. OCR không nhận dạng tốt chữ viết tay.

1. Quick start

  • Open a file: the Open file button (Ctrl+O), drag and drop a PDF into the window, or click a file in the Recent files list on the Home tab.
  • The Home tab is always the first tab (it cannot be closed): it holds the Open file button, a banner and the recent files list.
  • Multiple tabs, just like a browser: Ctrl+T new tab, Ctrl+W close, Ctrl+Shift+T reopen the tab you just closed, drag a tab to reorder, middle-click to close, right-click to close the other tabs.
  • EasyPDF remembers the page and zoom level of every file and reopens your previous files at startup (this can be turned off in the Help menu).

2. Viewing and searching

  • Zoom: Ctrl+mouse wheel, or the zoom box on the toolbar. Ctrl+0 fit page, Ctrl+2 fit width, Ctrl+1 100%. Zoom up to 6400% stays sharp (A0/A1 drawings).
  • Scroll: mouse wheel, arrow keys, PgUp/PgDn, Home/End, or drag the page with the Hand tool (H). Ctrl+G goes to any page; Alt+← returns to the previous position.
  • Rotate the view: Ctrl+R (right), Ctrl+Shift+R (left). This only changes how you view the file; to rotate permanently use the right-click menu in the thumbnail panel.
  • Find text: Ctrl+F, then type in the search box (Vietnamese with diacritics is supported); F3 / Shift+F3 next / previous result. Results are highlighted.
  • Select text by area: click the Text select tool (T) and drag; the text inside the area is copied to the clipboard when you release the mouse.
  • Dictionary: double-click an English word to see its Vietnamese meaning (offline). Translating selected text needs the Internet.
  • Full screen / presentation: F11 (hides the sidebar and banner). F9 toggles the sidebar.

3. The sidebar: thumbnails and outline

  • The Thumbnails tab: the first cell of the list is the banner (it scrolls with the list). Click a page to go to it.
  • Select several pages: Ctrl+click (add/remove), Shift+click (a range), Ctrl+A (all), Esc (clear selection).
  • Drag and drop to reorder pages: drag a page (or the whole selected group) to a new position — the red line shows where it will land. The program creates a new file in the new order; the original file is not modified.
  • ★ mark: flag important pages; later pick them again with "Select the ★ marked pages" to extract, print, export as images…
  • The Outline tab: the document's bookmarks; click one to jump to that section.

4. Right-click menu on thumbnails

Right-click a page (or a group of selected pages). Every action writes a new file; the original is always left untouched.

5. Right-click menu in the viewer

While the Hand or Text select tool is active, right-click on a page to: look up the word under the cursor, copy the page's text / image, save the page as an image, export text, extract embedded images, extract this page to a new PDF, print this page, mark ★, view properties, run OCR, or clean the scan background.

6. Annotating

Click Annotate to open the toolbar: pen, line, arrow, rectangle, ellipse, revision cloud, highlight, note, text, stamp / signature, insert image, eraser / redact, measure, magnifier…

  • Use the Pointer to select, move, resize and rotate annotations. Ctrl+Z / Ctrl+Y undo / redo.
  • Right-click an annotation: delete, edit its content, bring forward / send backward, change colour.
  • Inserted images / signatures: right-click → Remove image background to make a signature transparent; Rotate 90°; Save image (transparent PNG) to reuse it elsewhere; Copy image to paste it into another application.
  • Save: Ctrl+S writes the annotations into the PDF (it asks before overwriting); Ctrl+Shift+S saves as a new file.
  • A Redact area turns the page into an image so the hidden data cannot be recovered.

7. Page operations and other tools

  • The Page menu / Tools ▾ button: rotate, delete, extract, reorder, insert, blank page, split (every N pages / by outline / by range), merge several files, page numbering, watermark, bookmarks.
  • The Split pages and Merge files modes (top-right of the tab bar): see a grid of pages, select, rotate, delete, then export one file or split into single pages.
  • Compare 2 drawings (revisions), Compress to reduce size, Print (with annotations, 1–2 pages per sheet), save / open a work session (.json).
  • Every operation that writes a file always creates a new file and runs in the background; the status bar shows progress.

8. Language and ads

  • The interface comes in 6 languages: Tiếng Việt, English, Bahasa Indonesia, 한국어, 日本語, Filipino — use the Language menu.
  • Ad banners appear on the Home tab and at the top of the thumbnail list; they hide automatically in full screen, when the sidebar is off, or in Split pages / Merge files mode.

9. OCR — make image files searchable

For PDFs that are images / scans (text cannot be selected or searched).

  1. Click the OCR ▾ button on the toolbar and choose the pages: the current page, the pages selected in the thumbnail panel, all pages or a page range (or menu Tools → OCR, or right-click a thumbnail → OCR).
  2. Choose the language (Vietnamese + English / English / Vietnamese), the output (PDF with a text layer or just .txt) and the resolution (300 dpi recommended).
  3. Choose where to save. The program runs in the background and you can keep reading the document; when it finishes, the new file opens automatically.

The result keeps the page images but adds a hidden text layer: Ctrl+F finds text, and you can select / copy it. OCR works best on clear printed text; run Clean scan background first if the scan is yellowed or has shadows.

The OCR component is required (the ocr folder next to EasyPDF.exe). If it is missing, run the installer again and tick the "OCR" item.

10. Clean scan background

Whitens yellowed paper, shadows and grey backgrounds of scans and makes the text clearer.

  1. Click the Clean background button on the toolbar (or right-click a thumbnail → Clean scan background to process only the selected pages).
  2. Choose the level (Light / Medium / Strong), the colour (Keep colour / Greyscale / Black & white — smallest) and the resolution.
  3. The result is a new file; pages you did not select are kept as they are.
Processed pages become images, so any selectable text (if there was any) is lost. To keep it searchable: after cleaning, run OCR on the new file.

11. Opening Word, Excel and PowerPoint files

EasyPDF reads .doc, .docx, .rtf, .odt, .xls, .xlsx, .csv, .ods, .ppt, .pptx, .odp files: open them like a PDF (Open file button, drag and drop, or right-click the file → Open with).

  • The file is converted to PDF for viewing using software already installed on your computer: Microsoft Office is preferred (runs hidden, read-only, no macros); otherwise LibreOffice (free) is used.
  • The first time takes a few seconds; the PDF is cached, so reopening is almost instant. The original file is never modified.
  • Once opened, every tool works: search, annotate, extract pages, OCR… New files are placed next to the original file.
  • Ctrl+S on an Office tab = Save as PDF (with annotations, if any).
If the computer has neither Microsoft Office nor LibreOffice, EasyPDF tells you and opens the LibreOffice download page. The layout may differ slightly when converting with LibreOffice.

13. Frequently asked questions

Why don't operations edit the open file directly?

For safety: every page operation creates a new file. You compare, then replace the old file yourself.

What about password-protected PDFs?

The program asks for the password when opening; later operations reuse it.

OCR says a component is missing?

Run the EasyPDF installer again and tick "OCR", or copy the ocr folder next to EasyPDF.exe (the Portable edition already includes it).

Scrolling is choppy?

Very heavy pages (large-format drawings) need time to render lines: the program shows a blurry preview at once and then replaces it with the sharp version. Increasing the cache is unnecessary because the program limits itself according to your RAM.

Limitations

Office files are only converted for viewing (PDF → Word export is not available yet) — use Export text (.rtf) to open the text in Word. OCR does not recognise handwriting well.
